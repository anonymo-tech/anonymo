# Security

Report vulnerabilities through GitHub's private vulnerability reporting on this repository (Security → Report a
vulnerability). Please don't open a public issue for them.

Include the affected component, steps to reproduce and the impact you expect. Use test keys and test funds. Keep real
credentials, prompts and personal information out of reports.

Only the `main` branch is maintained. Component-level notes live in [`gateway/SECURITY.md`](gateway/SECURITY.md).
